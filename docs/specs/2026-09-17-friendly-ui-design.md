# 前端大众化重构：设计（Stage H）

> 实现现状：**已实现**（大主窗口 + PlainLanguage + 托比昂一键 + 老板键）。现役说明以 README 为准。

> 状态：已与用户确认（大主窗口+托盘常驻 / 关窗最小化到托盘 / 常驻使用指引 / 只做托比昂一键）

## 目标

把面向"工程调试"的前端改成**普通用户可用**的形态：

1. 主窗口优先（大窗口仪表盘），托盘降级为后台运行入口与状态灯；
2. 去除技术术语（PID/HWND/脉冲/EcoQoS/抖动/移出屏幕/重挂 → 大众化说法）；
3. 常驻四步使用指引；
4. 提供「托比昂战令一键启动」：默认 **每 30 秒按一次 Shift**，一键应用并开始。

## 非目标

- 不改动 Core/App 的输入、资源、重连逻辑与安全边界；
- 不改控制台版与诊断工具；
- 不做多语言、皮肤、开机自启。

## 术语映射（PlainLanguage，全部用户可见文案的唯一来源）

| 现在 | 改成 |
|---|---|
| 脉冲 / pulse | **自动按键**（"已自动按键 42 次"） |
| 目标 / PID / HWND | 游戏窗口 / "已连接《守望先锋》"（PID 仅出现在运行记录） |
| 重挂 / 重新检测 | **重新连接游戏** |
| 移出屏幕 | **隐藏游戏窗口** / 显示游戏窗口 |
| 前台跳过 | **你在玩游戏时自动暂停** |
| 资源策略 / EcoQoS / 优先级 | **后台省电模式**；失败 → "此电脑的电源设置不支持省电模式（不影响挂机）" |
| 抖动 / hold / focus 等待 | "间隔小幅随机" / "按键持续时间"（收进高级设置） |
| 日志 | **运行记录** |
| err=5 / Win32 错误码 | "权限不足：请尝试以相同权限运行"（原始错误码仅写运行记录） |

## 主窗口（~760×600，暖纸主题）

```
① 状态卡：● 已连接《守望先锋》 · 窗口 1707×912
          正在挂机 · 已自动按键 42 次 · 下次按键约 18 秒后
② 【 托比昂战令一键启动 】（大号焦赭按钮，副标题"每 30 秒自动按一次 Shift"）
   【停止】 【隐藏游戏窗口】
③ 使用指引（常驻四步）
④ 高级设置（折叠）：自定义按键… / 更多设置… / 打开运行记录 / 关于
```

- 关闭主窗口 → 隐藏窗口 + 托盘图标继续运行（本次运行首次提示气泡）；双击托盘唤回
- 托盘菜单保留精简版：打开主窗口 / 开始 / 停止 / 退出

## 一键预设（QuickPresets）

| 预设 | 键 | 间隔 | 其他 |
|---|---|---|---|
| 托比昂战令 | `shift` | 30s | 按住 200ms · 你在玩时自动暂停 · 间隔不抖动 · 按住优先级默认 |

点击流程：应用预设 → 写入配置 → 立即开始挂机 → 按钮变「停止」；若未检测到游戏，指引卡顶部提示"请先打开《守望先锋》"。
预设为纯数据 + 单测钉死（Shift=0x10、30 秒），防止未来被"顺手改配置"破坏。
